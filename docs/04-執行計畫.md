# 04 執行計畫：四個階段、KPI 與時間預算

> 目標：18–36 個月內達到月收 NT$100,000，之後維護時間降到每週 3 小時以下。
> 每個階段都列出「退出條件」——達到才進下一階段，沒達到就先修正而不是加碼。

## 階段 0：上線（第 1 週，約 4–6 小時）

| 任務 | 說明 | 完成判準 |
|---|---|---|
| 決定品牌、買網域 | 預設「錢算算」；網域 .com（Cloudflare Registrar 成本價）或 .tw（Gandi US$24／HiNet NT$800） | 網域可解析 |
| 部署到 Cloudflare Pages | 連 GitHub、`npm run build`、輸出 `dist`、`NODE_VERSION=22`、`PUBLIC_SITE_URL` | 網站可用 https 開啟 |
| 填 `site.ts` | `url`、`contactEmail`；`robots.txt` 的 sitemap 網址 | 建置通過 |
| Search Console ＋ Bing | 網域資源 DNS 驗證、提交 `sitemap-index.xml`；Bing 從 GSC 匯入 | sitemap 狀態「成功」 |
| GA4 | 建資源、填 `ga4Id` | 即時報表看得到自己 |
| 申請聯盟網、通路王 | 推廣者帳號（免費），通過後申請金融類活動 | 帳號通過審核 |

**退出條件**：網站上線、sitemap 提交、GA4 有數據、聯盟帳號送出。

## 階段 1：建立索引與內容基底（第 1–3 個月，每週 4–8 小時）

這是唯一需要較多時間的階段。重點不是流量，是**讓 Google 認識這個站、累積足夠內容通過 AdSense 審核**。

| 任務 | 數量／頻率 | 備註 |
|---|---|---|
| 寫文章 | 每週 1–2 篇，3 個月累積 **15–25 篇** | 用 `07` 的關鍵字清單；AI 起草、人工核數字 |
| 新增計算機 | 3 個月內 **＋2–3 個** | 優先：勞保老年給付試算（減給／展延）、年終獎金所得稅、雙貸族 DTI |
| 分享工具 | 每週 1 次 | Dcard 理財版、PTT CFP／Salary 版、Threads、FB 社團——以「我做了一個免費工具」的姿態分享**計算機**，附上使用情境；不要洗文章連結 |
| 申請 AdSense | 第 15 篇文章後 | 被拒等 2–4 週修正再送 |
| 填聯盟連結 | 通過後立即 | `OFFERS` 的 creditCards、brokers、loans 各至少 3 張 |
| 補作者簡介 | 第 1 個月 | 「關於」頁加一段作者背景（YMYL 信任訊號） |

**KPI**：索引頁數 ≥ 25、GSC 曝光量開始出現、AdSense 通過、聯盟卡片上線。
**退出條件**：AdSense 通過 ＋ 聯盟連結上線 ＋ 20 篇以上文章。

## 階段 2：長尾擴張與第一筆收入（第 3–6 個月，每週 3–5 小時）

| 任務 | 說明 |
|---|---|
| 長尾文章 | 針對 `07` 第二批關鍵字（情境型：「新青安寬限期結束怎麼辦」「年薪 80 萬繳多少稅」「休息日加班 10 小時多少錢」），每週 1 篇 |
| 程式化頁面（謹慎） | 針對高意圖長尾做**有獨特計算結果**的頁面，例如「月薪 3 萬–10 萬 加班費速查表」「年薪 40–200 萬 所得稅速查表」——每頁有真實計算數據與說明，**不要**做數百頁只換關鍵字的空殼頁 |
| 季節性準備 | 4–5 月報稅季前（3 月）更新所得稅內容、加「繳稅信用卡」導購；6–7 月貸款旺季前更新信貸內容 |
| 轉換優化 | 在工具結果區下方加「下一步」CTA（例：算完所得稅 → 繳稅信用卡；算完房貸 → 轉貸比較），觀察 GA4 `affiliate_click` 事件 |
| 數位商品試水 | 把房貸攤還表、所得稅試算做成 Excel／Google Sheets 模板，用綠界或 Lemon Squeezy 賣 NT$199–399 |

**KPI**：月 1–5 萬 PV、AdSense 月收 NT$1,000–5,000、首筆聯盟分潤。
**退出條件**：連續 2 個月有聯盟分潤入帳。

## 階段 3：規模化與合規（第 6–12 個月，每週 2–4 小時）

| 任務 | 說明 |
|---|---|
| 內容維持 | 每月 2–4 篇，優先更新舊文（更新日期、年度參數） |
| RPM 優化 | AdSense 自動廣告開啟 → 觀察 1 個月 → 手動版位（文中、側欄）A/B；財經站優化後 RPM 可到 US$5–8 |
| 聯盟最佳化 | 每月看聯盟網後台哪個活動核准率高、單價高，調整卡片順序與文案 |
| **稅籍登記** | 當月收入（廣告＋分潤＋商品）接近 NT$50,000 時辦理（2026/7 起未登記開罰）；可委託記帳士 |
| 第二站評估 | 若工具模式驗證成功，可用同一套程式碼開第二個利基站（例：勞工權益、租屋、保險試算） |

**KPI**：月 5–15 萬 PV、月收 NT$1–3 萬、聯盟收入 > 廣告收入。

## 階段 4：疊加高天花板收入（第 12–36 個月，每週 2–3 小時 ＋ 一次性開發）

研究結論：**只靠廣告＋聯盟，10 萬／月需要 30–40 萬 PV**，台灣利基站不容易；需要疊加不依賴 Google 點擊的收入。

| 選項 | 說明 | 為什麼 |
|---|---|---|
| **B2B 人資工具（首選）** | 多人、多週、變形工時的加班費批次計算＋匯出，月費 NT$500–1,500／公司 | 勞動部官方工具只能算 1 人 1 週；小型企業人資有真實痛點；67 家 × NT$1,500 = 10 萬 |
| 白標試算工具 | 房仲、代書、保經的嵌入式計算機（帶他們的 logo／聯絡方式） | 一次性 NT$5,000–20,000 或年費 |
| 策展型目錄 | 代書、記帳士、貸款顧問付費刊登 | 真正的經常性被動收入，但需要業務開發 |
| 數位商品擴充 | 退休規劃表、報稅檢查表、房貸比較表組合包 | 附加收入，單獨做天花板低 |

**KPI**：月收 NT$6–12 萬，其中 ≥ 30% 來自非廣告非聯盟。

## 時間預算總表

| 階段 | 期間 | 每週時間 | 累計一次性時間 |
|---|---|---|---|
| 0 上線 | 第 1 週 | — | 4–6 小時 |
| 1 建立基底 | 1–3 個月 | 4–8 小時 | ~70 小時 |
| 2 擴張 | 3–6 個月 | 3–5 小時 | ~50 小時 |
| 3 規模化 | 6–12 個月 | 2–4 小時 | ~70 小時 |
| 4 疊加 | 12–36 個月 | 2–3 小時 ＋ B2B 開發 40–80 小時 | — |

## 風險與對策

| 風險 | 機率 | 對策 |
|---|---|---|
| Google AI Mode 直接生成計算機、吸收頭部「XX試算」字 | 中（1–3 年） | 做官方／AI 做不到的情境（多段利率、多人批次、年度參數即時性）；經營品牌直接流量；B2B 收入不依賴搜尋 |
| AdSense 以「低價值內容」拒絕 | 中 | 先累積 15–25 篇原創深度文章、補齊四個法務頁、確認已被索引再送審 |
| 同質 AI 試算站湧入 | 高 | 差異化在正確性（測試、來源）、更新速度、說明品質；不比數量 |
| 法規參數更新不及時 → 錯誤數字傷信任 | 中 | `06` 維運行事曆 ＋ 頁面標示更新日期 ＋ 測試 |
| 稅務／法遵（稅籍登記、金管會紅線） | 低–中 | 月收 5 萬前辦登記；內容只做教育與比較，不推介特定證券／保單 |
| 聯盟活動停辦或單價調降 | 中 | 多平台（聯盟網＋通路王）、多類別（信用卡＋開戶＋貸款）、每月檢查後台 |
