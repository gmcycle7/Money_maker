# 05 上線部署指南：從零到可以收錢的網站

> 預估總時間：第一次 2–3 小時（不含等待審核）。每一步都有「完成判準」。

## 步驟 1：網域（15 分鐘）

| 選項 | 價格 | 建議 |
|---|---|---|
| `.com`（Cloudflare Registrar） | 約 US$10／年成本價 | **首選**：便宜、和 Pages 整合最順、含 WHOIS 隱私 |
| `.tw`（Gandi） | US$24／年 | 台灣感強；Cloudflare Registrar **不支援 .tw**，需在 Gandi 註冊後把 DNS 指到 Cloudflare |
| `.com.tw`（HiNet／PChome 買網址） | NT$599–800／年 | 同上 |

命名建議：短、好唸、不含數字；例如 `moneycalc.tw`、`suansuan.tw`、`qiansuan.com`。

**完成判準**：網域在 Cloudflare DNS 管理（Registrar 直接買，或外部註冊後把 NS 改到 Cloudflare）。

## 步驟 2：Cloudflare Pages 部署（15 分鐘）

1. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git** → 選這個 GitHub repo。
2. Build 設定：
   - Framework preset：**Astro**
   - Build command：`npm run build`
   - Build output directory：`dist`
   - Production branch：`main`（或你要用的分支）
3. 環境變數（Settings → Environment variables）：
   - `NODE_VERSION` = `22`
   - `PUBLIC_SITE_URL` = `https://你的網域`（不要結尾斜線）
4. 部署完成後 → **Custom domains** → 加入你的網域（DNS 在 Cloudflare 會自動建 CNAME 與憑證）。
5. 把 `www` 也加入，並設定 301 轉址到主網域（Rules → Redirect Rules），避免重複內容。

**完成判準**：`https://你的網域/tools/mortgage` 可以開啟且計算機能動。

> 為什麼不用 Vercel？Vercel Hobby 免費方案的 Fair Use 與 ToS 明定僅限非商業用途，放廣告與聯盟連結的網站不適用。Netlify 免費額度（約 15 GB／月）也偏小。Cloudflare Pages 免費方案靜態流量不計費、無商業限制。

## 步驟 3：更新程式碼設定（10 分鐘）

編輯 `src/config/site.ts`：

```ts
url: 'https://你的網域',
contactEmail: 'hello@你的網域',   // 建議用 Cloudflare Email Routing 免費轉寄到 Gmail
```

編輯 `public/robots.txt` 最後一行的 sitemap 網址。

想改品牌名：改 `SITE.name`、`SITE.nameEn`、`favicon.svg` 的字、`scripts/make-og.mjs` 的文字後執行 `node scripts/make-og.mjs`。

Commit → push → Cloudflare 自動重新部署。

## 步驟 4：Google Search Console（15 分鐘 ＋ 等待）

1. https://search.google.com/search-console → 新增資源 → **網域**（不是網址前置字元）→ 輸入 `你的網域`。
2. 把提供的 TXT 記錄加到 Cloudflare DNS（名稱填 `@`），回去按驗證（可能要等幾分鐘到幾小時）。**驗證後不要刪 TXT。**
3. 左側 **Sitemap** → 提交 `sitemap-index.xml`。
4. 用 **網址檢查** 對首頁與 6 個工具頁逐一「要求建立索引」。
5. **Bing Webmaster Tools** → 「從 Google Search Console 匯入」一鍵完成。

**完成判準**：Sitemap 狀態「成功」，幾天後「網頁」報表出現已建立索引的頁面。

## 步驟 5：Google Analytics 4（10 分鐘）

1. https://analytics.google.com → 建立資源 → 網站資料串流 → 取得 `G-XXXXXXXXXX`。
2. 填入 `src/config/site.ts` 的 `analytics.ga4Id`，push。
3. GA4 → 管理 → 事件：確認 `affiliate_click` 事件出現後（點一次測試），把它標為「關鍵事件」。

**完成判準**：即時報表看到自己的造訪。

## 步驟 6：聯盟行銷帳號（30 分鐘 ＋ 審核 1–5 天）

### 聯盟網 Affiliates.One（主力）
1. https://www.affiliates.one → 註冊推廣者 → 填網站網址、推廣方式（寫「理財試算工具與教學文章」）。
2. 通過後搜尋活動：關鍵字「信用卡」「證券」「開戶」「信貸」「貸款」「數位帳戶」，逐一申請。
3. 每個活動取得推廣連結後，填入 `src/config/site.ts` 的 `OFFERS`：

```ts
creditCards: [
  {
    id: 'cc-xxbank-cashback',
    name: '○○銀行 ○○卡',
    pitch: '一般消費 1%、指定通路 3%',
    highlights: ['新戶核卡送 NT$500', '免年費', '行動支付加碼'],
    url: 'https://track.affiliates.one/...',   // ← 推廣連結
    badge: '新戶首選',
    note: '活動至 2026/12/31',
  },
],
```

4. 請款門檻 NT$1,000；每月 15–23 日申請上月已確認收益。

### 通路王 iChannels（第二平台）
1. https://www.ichannels.com.tw → 註冊 → 手機認證、上傳身分證、銀行帳戶（戶名需同本人）。
2. 同樣搜尋金融類活動申請。請款門檻 NT$500。

### 補充
- **蝦皮分潤**（可選）：需社群 300 粉；適合文章中提到的理財書、計算機等商品。
- **銀行 MGM 推薦碼**（可選）：永豐 DAWHO、台新 Richart 等，每人 NT$100–200，可放在證券／數位帳戶頁的補充。

**完成判準**：至少 3 類（信用卡、開戶、貸款）各有 1 個以上活動連結上線，點擊後 GA4 有 `affiliate_click`。

## 步驟 7：Google AdSense（送審時機：15–25 篇文章後）

1. 確認：關於／聯絡／隱私權／免責四頁都在（已內建）、文章 ≥ 15 篇、頁面已被 Google 索引、沒有空頁或「即將推出」。
2. https://adsense.google.com → 申請 → 填網址 → 取得 `ca-pub-XXXXXXXXXXXXXXXX`。
3. 填入 `src/config/site.ts` 的 `adsense.client`，push（`<head>` 會自動加上 AdSense 程式碼供審核）。
4. 在 `public/` 新增 `ads.txt`，內容為 AdSense 後台給的一行：`google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`。
5. 審核通常 1–2 週。通過後先開 **自動廣告**（後台設定），觀察 1 個月；之後可在後台建立廣告單元，把 slot id 填入 `adsense.slots`，頁面的 `AdSlot` 會自動輸出。
6. 填寫稅務資訊（W-8BEN、新加坡稅務資訊）、設定付款方式（電匯；門檻 US$100）。

被拒常見原因與對策：
- 「低價值內容」→ 補文章到 20–25 篇、每篇 1,500 字以上、加作者簡介、等 2–4 週再送。
- 「網站無法存取／建置中」→ 確認 robots.txt 沒擋、每頁都有內容。

## 步驟 8：法遵與稅務（上線時 ＋ 月收近 5 萬時）

- 上線時：確認 `contactEmail` 有效；「關於」頁補上你的作者簡介（可用筆名，但描述真實背景）。
- 所有聯盟卡片已自帶揭露文字；文章若手動貼聯盟連結，請在連結附近加「（聯盟連結）」。
- **月收入（廣告＋分潤＋商品）接近 NT$50,000 時**：辦理稅籍登記（財政部 2025/9 規範，輔導期至 2026/6/30）。建議委託記帳士（月費約 NT$1,000–2,000），同時處理每兩個月的營業稅申報。
- 每年 5 月：AdSense 收入依「網紅綜所稅作業規範」申報（執行業務所得 9A，費用率約 45%，境外觀眾部分 50% 計入）；聯盟網／通路王會開扣繳憑單。

- [ ] Search Console 驗證、sitemap 成功；Bing 已匯入
